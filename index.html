[ 01 ] About

Named after the ferryman.

In myth, Charon carries travelers across the river. I do the same with ideas: from rough sketch to live website.

Every line of my code is hand-written. No page builders, no copy-pasted themes. Just HTML, CSS and JavaScript, shaped until it feels right.

I'm 24, based in Tehran, with an associate degree in programming and a B.Sc. in computer engineering in progress. I started with C# and SQL, spent time programming ARM microcontrollers, and settled on the front-end. Off the keyboard I follow the markets, so I think in data, timing and risk.
