# Flow Board — Kanban

A Kanban board where every action also works without a mouse: drag & drop, per-card move buttons (keyboard and touch), undo (Ctrl+Z), search, priority filter, due dates with overdue highlighting, JSON import / export.

## Highlights

- Immutable board model; a randomised test proves no card is ever lost or duplicated
- Imports are validated and cleaned before use
- Screen-reader announcements for every move

## Run it

Open `index.html` in a browser. Unit tests: `node --test` from the repository root.
