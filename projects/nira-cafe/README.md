# Nira Café — bilingual concept website

A concept site for a fictional specialty café, built to show real bilingual work: English / Persian with full RTL, Toman prices with Persian digits, and a Jalali date in the reservation confirmation.

## Highlights

- One page, JS dictionary i18n; remembers the choice; `?lang=fa` deep link
- Opening status computed in Tehran time
- Reservation form with per-field errors and `.ics` calendar export
- ARIA tabs with arrow-key navigation (direction-aware in RTL)

## Run it

Open `index.html` in a browser. Unit tests: `node --test` from the repository root.
