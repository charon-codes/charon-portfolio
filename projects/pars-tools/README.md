# Pars Tools — Persian utilities

Persian-first utilities: Jalali ↔ Gregorian conversion, number to Persian words (up to 15 digits), age in the Jalali calendar with days to the next birthday, and Persian ↔ English digit conversion.

## Highlights

- Calendar maths verified against the platform's Persian calendar (ICU) for ~73,000 consecutive days
- Accepts Persian, Arabic-Indic and English digits and separators
- EN / FA interface toggle

## Run it

Open `index.html` in a browser. Unit tests: `node --test` from the repository root.
